## 🎯 Goal

Predict bank account closures (churn) from customer data using Machine Learning. This type of model helps banks anticipate customer departures and implement targeted retention strategies.

---

## 📊 Dataset

- Banking customer data (demographic information, account history, behaviours)
- Full preprocessing pipeline: handling missing values, encoding, normalisation

---

## ⚙️ Methodology

1. **Exploratory Data Analysis (EDA)** — distribution and correlation visualisation
2. **Feature Engineering** — selection and transformation of relevant variables
3. **Modelling** — training a Random Forest classifier
4. **Evaluation** — accuracy, confusion matrix, classification report

---

## 📈 Results

| Metric | Score |
|--------|-------|
| Accuracy | **85% - 95%** |
| Model | Random Forest |
